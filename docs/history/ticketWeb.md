# 票务管理系统 - 技术栈分析文档

## 项目概述

- **项目名称**: 快速开发平台 (票务管理系统)
- **项目类型**: Vue.js 企业级管理后台系统
- **开发环境**: Node.js + Vue CLI 4.x
- **部署目录**: /ticketWeb/

## 核心技术栈

### 1. 前端框架与工具

- **Vue.js 2.6.x** - 核心前端框架
- **Vue CLI 4.5.x** - 项目构建工具
- **Vue Router 3.5.x** - 前端路由管理
- **Vuex 3.6.x** - 状态管理
  - 使用 `vuex-persistedstate` 实现状态持久化

### 2. UI 组件库（混合使用）

- **Element UI 2.15.x** - 主要 UI 组件库
- **Ant Design Vue 1.7.x** - 辅助 UI 组件库
- 支持主题动态切换功能

### 3. 网络请求

- **Axios 0.21.x** - HTTP 客户端
- **Vue-Axios 3.2.x** - Vue 集成
- 完整的请求/响应拦截器
- 统一错误处理和 Token 管理

### 4. 样式预处理

- **SCSS** - 主要样式预处理器
- **Less 2.7.x** - 辅助样式预处理器
- **Animate.css 4.1.x** - 动画效果库

### 5. 富文本编辑器

- **TinyMCE 5.10.x** - 主要富文本编辑器
  - 支持中文语言包
  - 自定义插件支持
- **Quill Editor 3.0.x** - 轻量级富文本编辑器

### 6. 代码编辑器

- **CodeMirror 5.60.x** - 代码编辑器
- **Vue-CodeMirror 4.0.x** - Vue 集成

### 7. 图表与可视化

- **ECharts 5.5.x** - 数据可视化图表库
- **Vue-ECharts 2.6.x** - Vue 集成

### 8. 地图服务

- **高德地图** - 地图服务提供商
- 自定义地图组件支持

### 9. 工具库

- **jQuery 3.6.x** - DOM 操作库
- **js-cookie 2.2.x** - Cookie 操作
- **screenfull 5.1.x** - 全屏功能
- **clipboard 2.0.x** - 剪贴板操作
- **fuse.js 6.4.x** - 模糊搜索
- **qs.js** - URL 参数处理
- **nprogress 0.2.x** - 进度条

### 10. 图片处理

- **CropperJS 1.5.x** - 图片裁剪
- **CompressorJS 1.0.x** - 图片压缩
- **html2canvas 1.4.x** - 页面截图

### 11. 其他功能组件

- **Swiper 8.0.x** - 轮播图组件
- **vue-draggable 2.24.x** - 拖拽功能
- **v-viewer 1.6.x** - 图片预览
- **vue-count-to 1.0.x** - 数字动画
- **jsencrypt 3.3.x** - RSA 加密
- **stompjs 2.3.x** - WebSocket 消息

## 项目结构特点

### 1. 模块化架构

```
src/
├── api/              # API接口模块化管理
├── components/       # 可复用组件
├── directive/        # 自定义指令
├── page/            # 业务页面组件
├── router/          # 路由配置
├── store/           # 状态管理
├── utils/           # 工具函数
└── views/           # 视图组件
```

### 2. 业务模块

- **文旅管理模块** - 合同管理、客户管理、直订管理等
- **票务中心** - 票务管理核心功能
- **订单管理** - 订单处理系统
- **系统管理** - 用户权限、角色管理
- **消息中心** - 消息推送系统
- **工作台** - 数据展示面板

### 3. 功能特性

- 权限管理系统
- 多主题切换
- 国际化支持（中、英、日、西语）
- 响应式布局
- 水印功能
- 打印功能
- 导入导出功能
- 图片上传与压缩
- 富文本编辑
- 图表数据可视化

## 总结

该项目是一个功能完善的企业级票务管理系统，采用了 Vue.js 生态系统的主流技术栈。项目架构清晰，模块化程度高，具备良好的可维护性和扩展性。在 UI 设计上采用了 Element UI 和 Ant Design Vue 的混合方案，提供了丰富的用户交互体验。

技术栈选择成熟稳定，适合企业级应用开发，但建议在后续迭代中考虑技术栈的统一性和现代化升级。
